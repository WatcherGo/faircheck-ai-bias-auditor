## 📖 Problem Statement
As AI becomes the backbone of critical decisions—from who gets a bank loan to who is shortlisted for a life-saving surgery—unseen algorithmic bias is creating a "Black Box" of discrimination. Companies often lack the accessible tools to audit their models for fairness, leading to outcomes that accidentally penalize marginalized groups.

## 💡 Our Solution
**FairCheck** is a professional-grade auditing platform designed to detect, visualize, and mitigate algorithmic bias. It bridges the gap between data science and ethical oversight by providing:
1. **Real-time Fairness Metrics**: Instant calculation of Disparate Impact, Statistical Parity, and Equal Opportunity.
2. **AI-Powered Root Cause Analysis**: Leverages Google's Gemini AI to identify which features are driving biased results and suggests mitigation strategies.
3. **Interactive Simulations**: Allows auditors to adjust decision thresholds and apply "Fixes" to see how fairness can be improved without sacrificing critical accuracy.

---

## 🚀 Key Features

- **Bias Metrics Visualization**: Specialized gauges and trend charts powered by Recharts.
- **Gemini AI Integration**: Contextual explanations and "Bias Fix" recommendations generated by AI.
- **Threshold Simulator**: Real-time recalculation of metrics as you adjust decision boundaries.
- **Audit Logging**: Automatic syncing of audit results to Google Firebase/Firestore.
- **Exportable Reports**: Generate professional plaintext audit reports for compliance documentation.

## ⚙️ Setup Instructions

### 1. Prerequisites
- Node.js (v18 or higher)
- npm or yarn
- A Firebase Project (for sync features)
- A Gemini API Key (from [Google AI Studio](https://aistudio.google.com/))

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/yourusername/faircheck.git
cd faircheck

# Install dependencies
npm install
```

### 3. Environment Configuration
Create a `.env` file in the root directory and add your Gemini API Key:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Running Locally
```bash
npm run dev
```
The app will be available at `http://localhost:3000`.

---

## 🚢 Deployment Instructions (Firebase)

### 1. Build the Project
```bash
npm run build
```

### 2. Firebase Init (If setting up for first time)
```bash
firebase init
# Select Hosting and Firestore
# Set 'public' directory to 'dist'
# Configure as a single-page app (Yes)
```

### 3. Deploy
```bash
firebase deploy
```

## 🛡️ Security & Privacy
FairCheck is designed with privacy-first principles. We do not store raw PII (Personally Identifiable Information). All auditing is performed on the client-side, with only aggregate metrics being synced to Firestore for historical tracking.
